# Third-party theme palettes

The built-in themes re-map the colours of the palettes below onto the app's own tokens (money colours and
chart palette included). Only palette values are used; no upstream code or assets are bundled. A few values
are tuned for contrast; each theme file under `src/shared/lib/theme/themes/` lists them.
