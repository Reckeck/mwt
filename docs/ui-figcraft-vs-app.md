# Холст (FigCraft, доски Full-*) и приложение: сверка

Ветка `feature/ui-redesign`, задача #214. Сверка по снимкам, не по коду: холст берётся из Chromium-рендеров досок, приложение снято через headless Chromium (CDP) на Vite с мок-API, окно Tauri не использовалось. Сценарий мока `year`, ПК 1280×800 и телефон 390×844, светлая тема; тёмная смотрелась выборочно (Траты, Вход, Каркас), на ней новых расхождений нет.

Снимки лежат в `.cache/shots/` (в git не входит):
- `.cache/shots/_compare/<набор>-<кадр>-light.png` — приложение на 1280 и 390 рядом (слева ПК, справа телефон);
- `.cache/shots/<набор>/<кадр>-year-<тема>-<ширина>.png` — исходные снимки (`stage1`, `stage2`, `stage2b`, `paths`, `stage3`, `stage4`, `stage5`, `stage6`, `walk`, `login`, `sandbox`, `encrypt`);
- кадры холста: `/home/wd/.claude/jobs/5a2aa1d4/tmp/fc/shots/v2-Full-<доска>.chromium.png` (в таблицах «доска · номер кадра»).

Классы: `критично` — ломает функцию или чтение; `забыли` — просто не сделано; `недоработка дизайна` — на холсте нет состояния или кадры противоречат друг другу; `осознанно` — принято раньше, ссылка на `docs/ui-redesign-vs-canvas.md` («vs-canvas»).

## Живая проверка слоёв (Esc, назад, фокус, край экрана)

Скрипт `walk/overlays-live.mjs` (вне репозитория) берёт список слоёв из `scripts/check-layout/overlay-list.mjs` (56 записей из `docs/ui-overlays.md`), открывает каждый шагами списка, ждёт, закрывает: на ПК Esc, на телефоне `closeTopLayer()` (то, что делает «Назад» на Android), затем отдельно системный `history.back()`. Мок `year`, 1280×800 и 390×844.

- Телефон: открыто 21, закрылись Back 21, обрезанных нет.
